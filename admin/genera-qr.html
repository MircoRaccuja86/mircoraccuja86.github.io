Generatore QR code contatti

Questo file è solo per uso tuo (non va caricato online). Inserisci l'indirizzo base della tua pagina GitHub Pages (es. https://tuonome.github.io/studio-vcard/vcard/) e carica il file contacts.json che stai usando: per ogni contatto verrà generato il QR code corrispondente, scaricabile come immagine PNG da stampare sul biglietto da visita.
